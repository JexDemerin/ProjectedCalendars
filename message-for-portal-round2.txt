SIBLING CARE (please count it this way, same as the CRM and the ShiftVerification script):
- Same caregiver, same day, EXACTLY the same start and end for 2+ children = sibling care (one rate). Those visits
  share a sibling_group. The caregiver's hours count ONCE for the group.
- Any difference, even 1 minute (5:00–7:00 and 5:01–7:01), is 1:1 care: sibling_group is null and the caregiver's
  hours count for each visit.
- Either way, each child uses their own full hours.
  Example: Naeem 5–7pm + Yusuf 5–7pm with Savanna → Savanna 2h; Naeem 2h, Yusuf 2h.
           Naeem 5–7pm + Yusuf 5:01–7:01pm with Savanna → Savanna 4h; Naeem 2h, Yusuf 2h.
- Visits whose WellSky caregiver name doesn't match exactly one Hired Caregivers email are not sent; the CRM lists
